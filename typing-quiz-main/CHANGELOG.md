# 敲脑壳 MindPop 更新日志

## Unreleased

### Added

- 支持把答案拆成“必答关键词 + 补充语境”，录入时可直观看到结构。
- 作答时可一次命中多个答案要点，并返回对应的命中位置。
- 题库整理 skill 支持 v2 答案结构、免输入上下文和可重复的独立要点。
- 编辑旧版打字题时保持 legacy 模式，避免把字面量 `{{...}}` 自动解释为新标记。

### Fixed

- 统一答案匹配中的空格、标点和大小写设置，旧题目继续兼容。
- 修复打字题“提示”按钮调用已移除的旧答案方法导致点击报错；提示现在通过统一匹配入口显示整条答案，并补齐 v2 答案的剩余要点。
