# MindPop 领域上下文

## 当前实现

- 测验：包含多条答案的回忆任务。
- 答案：当前以整条 content 匹配，按答案 ID 记录完成。
- 注释：comment 字段，不参与匹配；文本编辑支持末尾 `#注释#`。
- 当前“忽略空格”仅统一空白并去除首尾空格，内部空格仍影响匹配。

## 已同意、待实现的设计

- 免输入文字：`{{文字}}`，位于正文任意位置，不参与匹配，展示时保持位置。
- 作答要点：答案中可独立判定的最小充分内容；不机械等同于名词。
- 拆分标记：`||` 明确分隔要点，不按标点自动拆分；全部要点完成才算整条完成。
- 解释型注释保持独立；免输入正文不受隐藏注释设置影响。
- 未作答卡片保持现状，不新增提示或计数。
- 完整作答接受必答内容拼接或带免输入正文的完整句子。
- 相同要点同时点亮所有对应项，不做唯一性校验；已完成项不重复计分。
- 部分完成保留已答片段，整条仍按未完成进入复习。
