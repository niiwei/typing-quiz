# 关键词作答设计记录

状态：主要产品行为已确认；待形成实现规格和验收任务。此文件不是已实现声明。

## 已同意

1. `{{文字}}` 标记免输入正文，支持前置、中间、后置；标记不出现在答题展示中。
2. 末尾 `#注释#` 保持解释用途；正文不受隐藏注释设置影响。
3. 提供“设为免输入”“在此拆分”按钮和编辑预览。
4. `||` 明确划分作答要点；无标记时仍为一次作答。免输入片段不自动拆分要点。
5. 例：`降低成本{{、}}||提高效率`；各段可逆序答出，按原文顺序展示。
6. 未作答卡片保持现有空白视觉；部分作答后才显示已答片段和固定宽度占位。
7. 接受单个要点或整条答案；首版不支持任意多个片段自动分配。
8. 重复输入不计分；全部完成才增加顶部答案计数；结束时保留部分完成情况。
9. 忽略空格开启时匹配前移除空白，展示保留原文；前后端规则统一。
10. Skill 提取最小充分答案，保留方向、否定和关系等必要信息；平级知识优先拆成独立答案。
11. 编辑语法解析成有序结构保存；新格式显式版本化，旧数据不自动重解释。
12. 不支持嵌套；非法标记、空要点应在保存时检查。不做要点唯一性校验，不因重复要点拒绝保存。
13. 整条输入同时接受必答内容拼接及包含免输入正文的完整句子；解释型注释不要求输入。
14. 一次输入命中多个对应要点时，同时点亮所有匹配项，包括不同答案中的相同要点；已完成项不重复计分。
15. 部分完成保留已答片段；整条仍按未完成处理并进入复习。
