# 04 — 分次回忆一条答案并同时点亮全部匹配

Status: ready-for-agent

**What to build:** 明确拆分的答案支持逆序逐段完成，相同要点一次点亮，结算和复习保留未完成事实。

**Blocked by:** 03

## Acceptance criteria

- [ ] 启用 || 和在此拆分按钮，v2 多要点导入保存编辑导出往返无损；取消 v2 创建/更新/导入路径的唯一性检查和静默去重。
- [ ] 返回全部 answerId/partIndex；同条重复要点和跨答案相同要点均点亮；重复输入幂等，批量应用后才触发结束。
- [ ] 降低成本/提高效率正序、逆序、完整正文和必答拼接均按规格工作；任意不完整组合不误命中。
- [ ] 未作答卡片仍空白；部分完成固定宽度占位；完整后合成原文；中途放弃/超时显示已答和遗漏。
- [ ] 部分完成不增加完整答案计数；结算及复习请求分数一致，测验仍可复习，下一轮从空白开始。
- [ ] 组合练习切换、全重复反馈、两个答案同时完成、旧接口兼容有真实页面/API 回归。

## Execution boundary

执行本票前读取上级规格及工程规则；仅处理本票相关模块和验证。首次执行先确认用户已放行、依赖票已验收、工作区干净。以本票行为完成为提交边界，不开始下一票、不推送、不部署。
