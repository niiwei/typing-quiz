# 03 — 创建并练习包含免输入正文的答案

Status: ready-for-agent

**What to build:** 编辑者标记非核心文字，保存后关键词与完整句子都可答对，注释仍独立展示。

**Blocked by:** 02

## Acceptance criteria

- [ ] 实现 v2 segments/parts 契约与可重复的增量迁移；旧答案不重解释，未知版本和不一致 content 拒绝。
- [ ] 单要点支持前中后 context、转义、末尾解释；非法和空要点不保存；此票拒绝多要点并明确提示待后续支持。
- [ ] 编辑按钮和预览可用；保存重开、复制、导入导出再导入保持完整结构。
- [ ] 六个原始网站 AI 支持示例均可用关键词或正文答对；未作答视觉不变，隐藏注释不隐藏正文。
- [ ] 旧打字题和填空题往返不变；文字中的 HTML 不执行；完成正常结算。

执行本票前读取上级规格及工程规则；仅处理本票相关模块和验证。首次执行先确认用户已放行、依赖票已验收、工作区干净。以本票行为完成为提交边界，不开始下一票、不推送、不部署。
